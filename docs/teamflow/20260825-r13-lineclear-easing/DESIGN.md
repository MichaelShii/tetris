## 0. 现状与变更边界（先读）

1. **既有消行反馈**：`ui.js` 在消行后（快照 diff 反推行索引 `flashIndicesFor`）叠一层 **140ms 白色闪**（`FLASH_FILL = rgba(255,255,255,0.85)`，UI 计时器 `performance.now()` 驱动）。时机在「已塌缩后」，是事后补救式反馈，无「渐亮→渐暗」过程。
2. **本次变更**：把消行反馈升级为**引擎驱动的板内霓虹脉冲**——被消行不立即消失，先「过曝至白热 → 熄灭」，再塌缩。动画进度由引擎快照携带（`clearedIndices` + `animProgress`），UI 渲染**纯派生、无自有计时器**（与既有闪白的 UI 计时器机制相反）→ 暂停冻结/恢复续播天然成立（AC-4）。
3. **变更边界（硬）**：不改布局结构（§2.1 三列 `240|340|240`）、不改任何 CSS token（§5.1）、不改面板/遮罩/设置弹层/toast 组件、不改幽灵块/方块渲染基元、不改对外 phase 枚举与 UMD 签名、不改计分/音效/7-bag。全部视觉增量收敛于 `ui.js` 板渲染 + 引擎时序；**新增断言用 Canvas 内常量**（§5.1），零新增 DOM/CSS。
4. **与既有 140ms 闪白的关系（取代点）**：
   - **动画路径**（animMs=240 且非 reduced-motion）：霓虹脉冲**取代**白闪叠层——动画全程与塌缩帧均不得再叠白闪（避免「脉冲 + 事后闪」双重反馈，AC-1/AC-8 观感）。
   - **即时路径**（reduced-motion 或 animMs=0）：行为与现状**完全一致**，既有 140ms 白闪**原样保留**（AC-7 逐点等价，含既有视觉）。

## 1. 设计定位

- 一句话：**消行不是「消失」，是「熄灯」——被消行如霓虹灯管过曝至白热，随即整列熄灭，全板短暂屏息（时钟冻结），然后塌缩。**
- 沿既有原则：P2「状态即光效」（霓虹只表达状态与反馈，消行动画是最高频的正反馈，配给最亮的灯效）；P4「动效服务于节奏」（时长 ≤ 800ms、ease-out 指数曲线家族）。
- 新增动效家族成员：**ease-out-quart「霓虹脉冲」**——与 LEVEL UP toast（DOM 层 ease-out-quart）同缓动语言，形成「大反馈同一语族」的一致性。
- 克制口径：脉冲只落在 ≤ 4 行被消格上；**未消除行渲染逐像素不变**（AC-1）；不引入逐行错峰/粒子/粉碎（PRD §3「不做」）。

## 3. 关键页面线框

### 3.1 游戏板 clearing 帧（t ≈ 峰值，~100ms）

```
┌────────────────────────────┐
│                            │
│     ▣ ▣ ▣ ▣               │  ← 其余固定块：逐像素静止（不变）
│                            │
│  ▥ ▥ ▥ ▥ ▥ ▥ ▥ ▥ ▥ ▥      │  ← 被消行：白热脉冲（亮度 1.25，本格同色向白提亮）
│  ▥ ▥ ▥ ▥ ▥ ▥ ▥ ▥ ▥ ▥      │  ← 第二行（4 行同步消除时同样式，共用同一包络）
│                            │
│            ▣ ▣             │  ← 静止
└────────────────────────────┘
```

- 板内无活动块/幽灵块（锁定后、spawn 前，`piece == null`）；网格线、井底 `--board-bg` 不变。
- 左侧 HUD：分数/等级/行数冻结在锁定前数值（不提前计分，AC-3）；header `◉ PLAYING`。
- 动画每帧由引擎快照驱动（`animProgress ∈ [0,1]`），UI 无自有计时器。

### 3.2 动画期中途暂停（P / 空格 / 设置弹层自动暂停，AC-4）

```
┌───────────────┬────────────────────────────┐
│ 左面板（数据冻结）│  游戏板                     │
│ 分数 012340    │  ┌──────────────────────┐  │
│ 等级/行数 冻结   │  │ ▥ ▥ ▥  ← 脉冲定格在   │  │
│               │  │ （进度 p=0.5 帧，亮度   │  │
│               │  │   不再推进）            │  │
│               │  └──────────────────────┘  │
│               │   半透明 PAUSED 遮罩（既有 z-overlay）│
├───────────────┴────────────────────────────┤
│ 设置弹层（r12 毛玻璃模态，可叠加于暂停遮罩之上，z-overlay-card）│
└────────────────────────────────────────────┘
```

- 暂停 = 引擎停止 emit 动画帧 → 画面冻结于当前亮度帧（**进度不重置、不跳帧**，AC-4.2）；恢复后从冻结帧续播。
- 弹层打开（r12 自动暂停）同机制冻结；关闭弹层保持暂停，P/空格/Esc 按 r12 语义继续（弹层内 Esc 仅关弹层）。

### 3.3 reduced-motion / animMs=0 帧

与现状即时消除**完全一致**：锁定即塌缩，140ms 白闪照旧（该路径不产生动画/无 `clearedIndices` 播报帧之外的差异）。

## 4. 交互与动效说明

### 4.1 触发与脉冲包络（AC-1）

- 触发：锁定合并后 `cleared ≥ 1`（1~4 行，E3 上限不变）；`cleared = 0` 零动画直接走既有原子步。
- 包络（t = 已用时长 / T ∈ [0,1]，T 默认 240ms，容差 160~320ms）：

| 段 | 区间（占 T） | 亮度 B | 曲线 |
|---|---|---|---|
| 渐亮 | t ∈ [0, 0.40] | B = 1 + 0.25·u，u = 1−(1−t/0.40)^4 → 峰值 **1.25** | **ease-out-quart**：相邻帧亮度增量单调递减（QA 断言范围，AC-1） |
| 淡出 | t ∈ (0.40, 1.0] | B 由 1.25 → **0**（alpha 同步至 0） | 单调不升；推荐 ease-in-quart「先慢后快熄灭」，实现可用线性（QA 不约束此段增量符号） |

- 1~4 行共用同一包络、严格同步（同行 10 格同步）；峰值前曲线尾部自然形成 ~20ms「过曝定格」，无需另设保持段。
- 峰值保持亮度 ≥ 1.2 的持续时间 ≥ 1 帧（保证可观测、可断言）；结束帧 B=0（无残留亮度帧，AC-6）。

### 4.2 动画期间的输入 / 时钟 / 暂停（AC-4/AC-5）

| 事件 | 行为 |
|---|---|
| 左/右/软降/硬降/旋转 | **全部忽略**：不排队、不缓冲、不产生动作事件；动画结束后首个输入生效（AC-4.1） |
| 自动下落时钟 | **冻结**：dt 不累计、无 tick；不出现「动画结束瞬间新块连降/积压下落步数」（AC-5） |
| P / 空格暂停 | 动画期有效：画面冻结于当前帧（进度冻结），恢复从冻结帧续播（AC-4.2） |
| 设置弹层打开（r12） | 自动暂停 → 动画冻结；关闭保持暂停；P/空格恢复续播；弹层内 ESC 仅关弹层（AC-4.3，r12 全行为回归） |
| `sfx('clear')` | **动画开始帧**播放恰 1 次（AC-3）：声音先锚定反馈，视觉随后跟上 |

### 4.3 与既有 140ms 白闪的关系（取代点，实现红线）

- 动画路径：**不再产生** `flashIndicesFor` 白闪（触发抑制从动画首帧持续至塌缩完成后首个快照，避免「脉冲+事后闪」双重反馈）。
- 即时路径：白闪机制**原样保留**（AC-7 现状等价）。实现建议：板渲染器维护 `animating` 标记，动画路径期间置位并抑制白闪；`flashIndicesFor` 反推逻辑可保留仅服务即时路径（动画路径用引擎 `clearedIndices` 精确值）。

### 4.4 降级（AC-7）

- `prefers-reduced-motion: reduce`：装配时以 `animMs = 0` 创建引擎 → 完全跳过动画，与即时基线逐点等价（棋盘/计分/行数/等级/音效次数/状态序列；无残留状态、无额外帧）。
- `animMs = 0` 为正规配置项（非测试后门），语义同 reduced-motion。

### 4.5 GAME_OVER 顺序（AC-6）

- 消行后 spawn 出生碰撞 → OVER：动画**完整播放**（≤ 320ms）后才呈现 OVER；OVER 后动画状态清空（快照不再含 clearedIndices/animProgress）。顺序 = 既有「消行→spawn→碰撞→OVER」仅整体后移 T。

## 5. 视觉规范

### 5.1 设计 Token

**CSS token：零新增、零覆盖**（全部复用 §5.1 既有）。**新增「Canvas 内常量」**（与 `ui.js` 既有 `FLASH_MS`/`GHOST.*` 常量同一位置、同注释规范，供 QA 数值断言）：

| 常量 | 默认值 | 说明 |
|---|---|---|
| `ANIM_MS` | 240（容差 160~320） | 引擎构造参数；0 = 即时（AC-9）；满足 P4 ≤ 800ms |
| `ANIM_PEAK` | 1.25（下限 1.2） | 峰值乘性亮度（AC-1），QA 断言边界 |
| `ANIM_PEAK_T` | 0.40 | 峰值到达点（占 T），渐亮段 ease-out-quart |
| 亮度函数 | B(t)（§4.1） | 渐亮段帧增量单调递减可数值断言（AC-9 用例①） |

### 5.2 霓虹脉冲视觉规格（每被消格）

- **色相保持**：每格沿用自身方块色（`TetrisGame.COLORS[type]`，§5.2 七色不变），仅做亮度/alpha 动画——不换色、不混入白闪整层覆盖。
- **提亮实现取向**（合成器友好，AC-8）：乘性提亮可近似为「既有烘焙 sprite 原样绘制 + 白热叠加层按 B 渐进」（叠加透明度 ∝ 亮度增量），淡出段用 `globalAlpha = B/1.25` 渐隐；**禁止**逐帧 `ctx.filter`/重新烘焙 sprite/动画 `box-shadow`。
- 过曝上限：峰值 B=1.25 时叠加白热不透底但不过曝溢出（格内完整、glow 增强感由叠加自然产生，不新增辉光强度开关）。
- 结束帧：B=0（alpha 0）后紧接塌缩帧——被消格在淡出末不可见，塌缩不留视觉跳变。
- **静止区逐像素不变**：未消除格按既有 `drawCell` 确定性绘制（整板重绘或局部 clip 均满足，见 §7）。

### 5.3 方块配色 / 幽灵块 / 网格线 / 井底

全部保持（§5.2/§5.6 既有），本次零改动。

### 5.4 本次零改动清单（防回归）

- `style.css`：**零改动**（动画全在 Canvas，CSS 的 `@media (prefers-reduced-motion)` 既有块只管 DOM 动效，板内动效降级由 JS 装配承担，见 §6）。
- `index.html`：零改动（无新 DOM/按钮/设置键，PRD §3「不做」：不新增消行动画开关）。
- `audio.js`：零改动（`clear` 事件时序由引擎回调触发，发声职责不变）。

## 6. 可访问性要点

| 类别 | 要求 | 落地 |
|---|---|---|
| 动效降级 | `prefers-reduced-motion` 下无动画（P4 硬约定） | `ui.js` 装配层 `matchMedia('(prefers-reduced-motion: reduce)')` 检测 → 引擎 `animMs = 0` 即时路径，与现状逐点等价（AC-7）；CSS 侧既有 `@media` 只覆盖 DOM 动效，板内动效必须走 JS 检测 |
| 非视觉等价反馈 | 视觉脉冲缺失时反馈不丢失 | `sfx('clear')` 恰 1 次（动画开始帧）在所有路径保留（AC-3/AC-7），即时路径另有既有 140ms 白闪 |
| 无闪烁/癫痫风险 | 不构成 3 次 ≥ 1s 内频闪（WCAG 2.3.1） | 单次平滑脉冲、无重复闪烁；峰值保持 ≤ ~20ms 且为曲线自然平台；1~4 行同步不叠加频闪 |
| 时长 | 动效 ≤ 800ms（P4 / WCAG 2.3.3 域内） | T=240ms（容差 160~320ms） |
| 玩家可控 | 动画可暂停/恢复 | 与既有暂停机制（P/空格/弹层自动暂停）完全协同（AC-4），暂停即冻结 |
| 对比度 | 不劣化既有 AA 对比 | 脉冲只作用于方块格（非文字/交互元素），面板/按钮对比不受影响 |
| 读屏 | 无需新增播报 | 动画为装饰性反馈（替代现有白闪），无新增语义化元素（AC-10 快照字段是内部契约，不进无障碍树） |

## 7. 性能注意（AC-8，支撑 FPS ≥ 55 / 响应 ≤ 100ms）

- 动画重绘范围：仅 ≤ 4 行（≤ 40 格）参与脉冲；每格每帧至多 2 次绘制基元（`drawImage` + 白热叠加 fill），整帧负载不高于无动画帧量级。
- 无逐帧 DOM 更新、无逐帧 `shadowBlur`/`box-shadow`/`backdrop-filter`/`filter`（烘焙 sprite 内辉光不变）。
- 渲染策略二选一（实现自由度）：① 整板重绘——静止块按既有路径确定性绘制（简单、与 `renderAll` 一致）；② 仅 clip 被消行区域局部重绘。两者均满足「未消除行逐像素不变」（AC-1）与 FPS ≥ 55（AC-8）。
- 不再使用既有白闪的 `performance.now()` UI 计时器驱动动画——进度全部来自引擎快照（`animProgress`），暂停冻结零额外开销。
