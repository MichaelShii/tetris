现况 vs 新案（竖屏底部操作区）

现况 r16/r19：单行 6 键 × 48px（点按容错低、盲按易误触）
◀▶⟳▼⤓📦
新案：左手十字（64px×4）+ 右手大旋转（96px）+ Hold 卫星（56px），拇指双区分工
⤓◀▶▼ ⟳ 📦
面积对比：方向键 48²→64²（+78%）、旋转 48²→96²（4 倍）、键距 8→12px； 全部 ≥ Android/苹果推荐的主操作目标（≥48dp / 44pt），高频键（旋转）显著大于低频键（Hold）。 十字布局手指不换位：拇指以中心为轴小幅滑动即可覆盖四键。

改动面与契约（实现期预估）

  • index.html：#touch-controls 内部加两簇 wrapper（.tpad-cross / .tpad-main），6 个 .tkey[data-action] 原样保留 → ui.js 按 data-action 绑定，触控绑定逻辑 0 改动；设置弹层新增「外观」分组（操作区背景四选一 segmented 按钮）。
  • style.css：重写 .touchpad 布局块；新增 3 个尺寸 token（--tpad-key-dir / -hero / -hold，替代单一 --tpad-key）；四套背景各为一个修饰类（如 .touchpad--skin-glass / -float / -fade / -pod），html 根类或容器类驱动。
  • ui.js：新增 dockSkin 设置项读写（枚举 'glass'|'float'|'fade'|'pod'，默认 'fade'），装配时给 #touch-controls 挂对应类、设置弹层切换即时生效。
  • persist.js：settings 新增 dockSkin 键（tetris.dockSkin），非法值回退默认；沿用「能力探测失败降级内存」约定。
  • 验证脚本：verify-ui（四套类 ↔ 枚举值交叉断言、设置项持久化往返）与 qa-e2e（切换即时生效 + restart 保持）同步补；data-action ↔ TOUCH_KEYS 交叉断言不变。
  • 键盘路径、桌面视觉、遮罩/弹层层级（--z-touchpad:5）零变化。
  • 不在本次范围：顶部统计行、开始游戏/暂停/重新开始、⚙ 设置按钮——位置与样式均保持现状（r19 布局），本稿画出仅为呈现完整屏幕。
