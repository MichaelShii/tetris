## 1. 背景与目标

**痛点**：当前移动端触控区为底部一行 6 个 48px 小键（r19 AC-3 单行随流排布），键小、单排、「按着不顺」，横屏侧轨同样为小键。

**目标**：
1. 参考经典掌机布局重排触控区：左侧十字方向键（上=硬降、左/右=横移、下=软降、中心 ✛ 装饰不可点）+ 右侧大号旋转键簇（旋转主键在下、Hold 卫星键在上），大键位、间距舒适。
2. 尺寸分档：标准档 方向 64 / 旋转 96 / Hold 56、键距 12px；紧凑档（竖屏且宽≤359 或高≤639）降为 56/80/48；320px 宽不横向溢出，保持 r19 一屏零滚动。
3. 操作区背景四套方案（A 玻璃 dock / B 无底浮键 / C 渐隐托盘 / D 双簇座舱）全部落地为「设置弹层 → 外观分组 → 操作区背景」设置项，默认 C 渐隐，切换即时生效并持久化（重开/刷新恢复），非法值回退默认。
4. 横屏侧轨重排：左轨=十字、右轨=Hold+旋转（键径 56/80/48），底部贴 safe-area、零遮挡棋盘中列。
5. 零回归红线：六键功能与 `.tkey[data-action] ↔ TOUCH_KEYS` 契约一一对应、触控=键盘事件回放器路径零逻辑改动、长按/多指/守卫与 r16 一致；非触屏桌面设置弹层不显示「外观」组、桌面视觉零变化；引擎 game.js / 音效 audio.js 0 diff、代码头 VERSION 不动。

**参考设计稿**（用户已逐轮评审通过：标准档、横屏、四套背景均确认）：`docs/teamflow/drafts/20260829-touchpad-cross-design-draft.html` —— 实施以设计稿为准。

## 2. 用户故事与验收标准

### US-1 掌机式按键布局（竖屏）
*作为移动端玩家，我希望触控区像掌机手柄：左十字 + 右旋转簇、大键位，按得准、按得爽。*

- **AC-1 [P0] 布局契约**：S 竖屏触控区重排为左十字簇 + 右旋转簇。十字四键动作：上=硬降、左=横移、右=横移、下=软降，中心为 ✛ 装饰；右簇上方=Hold 卫星键、下方=旋转主键。六键 `data-action` 与 `TOUCH_KEYS` 契约一一对应（action 字面量、数量、顺序与 r16 一致，零改名零重映射）。
- **AC-2 [P0] 尺寸规格**：标准档 方向键 64px / 旋转 96px / Hold 56px、键距 12px；紧凑档降为 56/80/48（键距按设计稿核定）。computed-size 实测与规格偏差 ≤1px。验证：verify-ui 静态断言 + QA 截图。
- **AC-3 [P0] ✛ 装饰纯装饰**：中心 ✛ 可见、非交互——无 `data-action`、`pointer-events:none`、不产生任何输入/回放事件；`aria-hidden` 不入读屏。验证：verify-ui 断言 + qa-e2e 点击零事件。
- **AC-4 [P0] 紧凑档判定与 320px 不溢出**：`portrait && (width≤359 || height≤639)` 命中紧凑档 56/80/48；320×568 视口 `scrollWidth ≤ clientWidth`（横向零溢出、无滚动条）。验证：verify-ui 断点断言。
- **AC-5 [P0] 一屏零滚动保持（承继 r19 AC-1）**：S 竖屏 320×568 / 375×667 / 390×844 下 `documentElement.scrollHeight ≤ clientHeight`；统计、控制钮、棋盘、Hold、Next、双簇触控区包围盒全部落首屏。验证：verify-ui + QA 视口截图。

### US-2 触控行为零回归
*作为玩家，我要求换了键位排布但手感契约不变：长按连移、多指并发、状态下的守卫一个都不能少。*

- **AC-6 [P0] 逐键等效 + 回放器零逻辑改动**：六键点击 = 键盘事件回放逐键等效（旋转含踢墙、硬降落底锁定/计分/onSfx 序列完全一致）；长按=DAS/软降 repeat、多指并发互不串扰、PAUSED/OVER 点击无副作用、触摸防滚动/缩放/选中——均与 r16 AC-2~AC-10 断言一致，键盘事件合成与分发代码路径 0 逻辑 diff。验证：qa-e2e 既有触屏仿真用例沿用 + git diff 审查。

### US-3 操作区背景四方案
*作为玩家，我希望操作区背景可自选：玻璃 dock、无底浮键、渐隐托盘或座舱，且选完说好，下次打开还在。*

- **AC-7 [P0] 「操作区背景」设置项**：设置弹层新增「外观」分组 → 「操作区背景」四档单选：A 玻璃 dock / B 无底浮键 / C 渐隐托盘 / D 双簇座舱；默认 C 渐隐。切换即时生效——不重载、不重置对局、引擎快照无漂移。验证：qa-e2e 切换用例 + 截图对拍。
- **AC-8 [P0] 持久化与非法回退**：选择持久化存储（重开/刷新后恢复上次选择）；存储值非法/缺省时回退默认 C；与既有设置持久化通道同源、同键名命名规范；无旧存档场景（首次无该键）即默认 C。验证：persist 单测 + 手动刷新。
- **AC-9 [P0] 皮肤作用域**：操作区背景皮肤作用于 S 竖屏 dock 与横屏侧轨两处；M/L（≥600px）行式底栏视觉零回归——恒玻璃、不随皮肤变化。验证：verify-ui 断言 + git diff 审查 style.css 作用域。

### US-4 横屏侧轨
*作为横屏玩家，我希望左右手各管一簇：左十字、右 Hold+旋转，贴边不挡棋盘。*

- **AC-10 [P0] 横屏侧轨重排**：横屏左轨=十字（键径 56）、右轨=Hold+旋转（Hold 48 / 旋转 80）——键径按 56/80/48 分派；侧轨底部贴 safe-area（`env(safe-area-inset-bottom)` 避让）；侧轨包围盒与棋盘中列零遮挡（不与 playfield 列区重叠），z-index 层级不遮键（承继 r21 修复防回归）。验证：verify-ui 断点断言 + QA 截图。

### US-5 零回归出口
*作为产品，我要求这次改动桌面无感、引擎清净、验证全绿。*

- **AC-11 [P0] 引擎/音效 0 diff**：game.js 与 audio.js 0 行 diff；代码头 VERSION 三模块一致（verify-constants 绿）。验证：git diff 审查 + verify-constants.cjs。
- **AC-12 [P0] 桌面无感**：非触屏桌面（has-touch=false，判定沿用 r21）设置弹层不渲染「外观」组；桌面视觉 0 变化；≥600px 全档与键盘流操作体验与现状一致。验证：verify-ui 断言 + 桌面截图对拍。
- **AC-13 [P0] 七套全绿**：verify-game / verify-ui / verify-audio / verify-constants / verify-persist / assembly-check / qa-e2e-jsdom 七套全绿；既有断言零改动或纯追加（旧期望不变）；r23/r21/r19/r16 既有用例零回归。

### P1（重要，不阻塞）
- **AC-14 [P1] 触控目标与可访问性**：全部触控键实测 ≥44px（最小为紧凑档 Hold 48px，满足）；✛ `aria-hidden`；「外观」组键盘可达、单选项聚焦态清晰；触屏键位图例与十字/旋转含义一致（承继 r16 AC-13 不误导）。
- **AC-15 [P1] DESIGN token 一致**：四方案视觉均复用既有玻璃/霓虹 token（零新增色板/阴影体系）；C 渐隐默认态不降低棋盘辨识度/对比度（正常亮度下棋盘清晰可辨）。

## 3. 范围与非目标（Non-goals）

- **不改**：桌面布局与键鼠操作、游戏引擎计分/锁定/音效逻辑、TOUCH_KEYS 契约字面量、has-touch 判定（r21）、r19 一屏零滚动机制。
- **不做**：自定义键位/键尺寸调节、滑动手势或虚拟摇杆（✛ 纯装饰不承载输入）、触觉反馈（haptic）、连点宏/多键组合键、操作区背景动画时长/透明度自定义（四档为固定皮肤，不做参数化）。

## 4. 交互流程摘要

1. **竖屏（S）**：dock 渲染左十字簇（上/左/右/下 + 中间 ✛）+ 右旋转簇（Hold 上、旋转下），背景按「操作区背景」皮肤（默认 C 渐隐）；点按任一键 → 键盘事件回放器 → 引擎既有路径（held/DAS/软降 repeat 复用），零新速率常量。
2. **紧凑判定**：`portrait && (width≤359 || height≤639)` → 56/80/48；否则标准 64/96/56（键距 12px）。
3. **横屏**：dock 拆为左右侧轨（左=十字 56，右=Hold 48+旋转 80），贴 safe-area、不挡棋盘中列。
4. **设置**：打开设置弹层 → 「外观」分组 → 「操作区背景」四档单选；选择即时生效 → 写入持久化；重开/刷新恢复；读取到非法值回退默认 C；非触屏桌面整组隐藏。
5. **零回归**：桌面/M/L 恒玻璃底栏不随皮肤变化；触控路径、引擎、音效零改动。

## 6. 依赖与风险

**依赖**：
- 设计稿 `docs/teamflow/drafts/20260829-touchpad-cross-design-draft.html`（用户已确认，实施唯一视觉依据）。
- 触控层基线：r16 键盘回放器/守卫契约、r17 响应式断点、r19 一屏零滚动骨架、r21 has-touch 门控与侧轨 z-index 修复、r9 设置弹层结构、persist 设置持久化通道。

**风险**：
- **R1 紧凑档几何**：双簇并排宽度在 320px 下的数学余量紧（设计稿已定稿锚点/键距）。缓解：M1 先以 verify-ui 静态断言锁定 320px 零溢出，若溢出按设计稿回退键距/锚点，出口仍为 AC-4。
- **R2 高度预算**：十字 3 行×64（标准 216px）抬高 dock 竖向占用，320×568 一屏零滚动（r19 AC-1）需压缩棋盘等比尺寸。缓解：紧凑档覆盖高≤639 场景已收窄高度（3×56+2×12=192px），M1 冒烟验证三档视口，出口为 AC-5 断言。
- **R3 皮肤 CSS 层叠**：皮肤变量若误作用到 M/L 底栏。缓解：皮肤样式仅挂 S 竖屏/横屏作用域（AC-9 断言 + git diff 审查）。
- **R4 持久化兼容**：存量存档无「操作区背景」键。缓解：缺省=默认 C，非法值回退（AC-8 单测覆盖）。
- **R5 回归红线**：game.js/audio.js 必须 0 diff。缓解：改动面仅限 index.html/style.css/ui.js/persist.js + 验证脚本（断言纯追加或登记改写），AC-11/AC-13 出口审查。

## 7. 里程碑建议

- **M1 布局骨架**：十字+旋转簇 DOM/CSS，标准/紧凑两档 + 320px 零溢出 + 一屏零滚动冒烟（AC-1~AC-5）。
- **M2 设置与横屏**：「外观」组 + 四方案皮肤 + 持久化/非法回退（AC-7~AC-9）；横屏侧轨重排与零遮挡（AC-10）。
- **M3 回归出口**：验证脚本断言纯追加/登记改写 + 七套全绿 + 桌面/M/L 对拍 + 0-diff 审查（AC-11~AC-13；P1：AC-14、AC-15）。

1. **状态核对**：当前分支 main、工作区干净（无未提交改动，无需处理未提交改动）；基线提交 b7017eb（docs: 提交设计草稿 20260829-touchpad-cross-design-draft）。
