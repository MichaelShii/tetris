## 2. 线框描述

### 2.1 S 竖屏 dock（键帽校正）【修订 · 仅键帽，布局零动】

沿用 r24 布局：左十字簇（grid 3×3，上硬降/左·右横移/下软降/中心 ✛ 装饰）+ 右 Hold/旋转簇（Hold 上 48、旋转主键 80，纵向排列）；标准档 64/96/56（键距 12）、紧凑档 56/80/48（键距 10）。

本次仅改两处视觉：
1. **全键帽正圆**：`.touchpad .tpad-cross .tkey` 与 `.touchpad .tpad-main .tkey--rotate/.tkey--hold` 统一 `border-radius:50%`（Hold 现漏设、继承 `--radius-md` 成圆角方形 → 补齐；AC-5）。
2. **旋转主键主色增强**：常亮环 + 微底 + 图标主色（规格见 §4.3，AC-6）。

三态、按压 `scale(0.94)`、辉光伪元素、touch-action 全部维持 r24/r16。

### 2.2 手机横屏侧轨（.rail 化）【修订 + 裁定】

**结构（AC-2）**：轨道由独立 `.rail` 元素承载（`.rail--l` 左轨 / `.rail--r` 右轨），弃用 `.touchpad::before/::after` 全边描边模拟；皮肤背景在横屏作用域挂 `.rail`（§4.4）。

```
┌─────────────────────────────── 横屏 <600px ───────────────────────────────┐
│[.rail--l]  边框只画右侧 1px --line        中列板框(居中于 [212, vw−212])   [.rail--r]
│ 左轨≈212px  bg rgba(35,35,45,.45)                                        │右轨≈104px
│  ┌十字 56×56 grid 3×3 gap10┐                                              │ ┌Hold 48 正圆┐
│  │ .  ⤓ . │                  │  底贴 safe-area-inset-bottom                │ └──┘        │
│  │ ◀  ✛ ▶ │                  │  左右各贴 safe-area-inset-left/right         │ ┌旋转 80 常亮环┐
│  │ .  ▼ . │                  │                                              │ └────┘      │
│  └──────────────────┘                                                      │边框只画左侧1px --line
└────────────────────────────────────────────────────────────────────────────┘
```

- **左轨 `.rail--l`**：宽 = 3×56 + 2×10 + 2×12 ≈ **212px**（内含十字簇），`border-right:1px solid var(--line)`（**单边描边**，非全边）；右轨 `.rail--r`：宽 = 内容收口 ≈ **80+2×12=104px**（Hold 48 居中对齐于旋转 80 上方），`border-left:1px solid var(--line)`。
- 两轨底色 `rgba(35,35,45,0.45)`（同 r24 §2.3）、`border-radius:var(--radius-md)`；底部 `padding-bottom: calc(… + env(safe-area-inset-bottom))`，左右贴 `safe-area-inset-left/right`；`z-index:var(--z-touchpad)`，轨内键 `z-index:1` 盖轨（承继 r21 修复语义）。
- **键径（AC-4 保持）**：左十字 56 / 右 Hold 48 + 旋转 80 —— 沿用 r24 裁定（取代设计稿内 52/76/46），断言零改动。
- 右轨收窄（212→104）为【新增】裁定：与设计稿 rail--r 窄面板一致、向右让出更多中列余量（遮挡只减不增）；verify-ui 对「右轨宽」的锁档若涉及既有 212 断言，仅允许**纯追加**新断言（AC-14）。

**M/L 横屏裁定（AC-3，写入 TECH）**【新增】：设计稿仅画手机横屏 → **≥600px 横屏维持行式底栏恒玻璃、不渲染 `.rail`/十字簇**；侧轨仅作用于「触屏且视口 <600px 横屏」。

### 2.3 设置弹层「外观 → 操作区背景」2×2 缩略选择器【新增 · 取代 r24 横排单选】

```
外观
  操作区背景
  ┌─ 2×2 grid（gap 10~12，列 1fr 1fr）────────────────────────────┐
  │ ┌──────────┐  ┌──────────┐                                    │
  │ │ ▓▓▓▓▓▓▓▓ │  │  (无底)   │   ← 预览面：真实皮肤 mini-dock（见下）│
  │ │ A 玻璃 dock│ │ B 无底浮键 │   ← 名称另起一行（--fs-xs）          │
  │ └──────────┘  └──────────┘                                    │
  │ ┌──────────┐  ┌──────────┐                                    │
  │ │ ▓▓▓▓▓▓▓▓ │  │  ◉ ◠ ◠   │   ← C 渐隐托盘（默认选中描边 --primary）│
  │ │ C 渐隐托盘 │ │ D 双簇座舱 │                                    │
  │ └──────────┘  └──────────┘                                    │
  └─────────────────────────────────────────────────────────────┘
```

- **选项结构**（radio 语义）：`<label>` 包 `input[type=radio][name=dockSkin]`（视觉隐藏）+ 预览面 + `<span>` 名称行。
- **预览面（AC-8 真实呈现）**：高 48px、宽 100%（tile 宽 ≈110~136px），`border-radius:var(--radius-md)`；渲染**真实皮肤**——复用皮肤 CSS 变量在 mini 尺度画 dock 背景（A：`--glass-bg`+blur 玻璃带；B：透明底仅键点投影；C：底部渐入深玻璃渐变；D：两簇主色光环托），键以迷你键点示意（十字 4 点 7px `--surface-2`+`--line` 描边、主键点 10px 带 `--primary` 描边），**非静态图标占位**。
- **名称行**：预览面下**另起一行**，`--fs-xs`、`--muted`、`white-space:nowrap` + 省略兜底；文案：`A 玻璃 dock` / `B 无底浮键` / `C 渐隐托盘` / `D 双簇座舱`。
- **选中态（AC-9）**：tile 描边转 `--primary`（1px，`border-color` 切换不改变布局）+ 右上角勾选徽标（圆 16px `--surface-2` 底 + `--primary` 描边 + `--primary-hi` ✓）三选其成；四档互斥，radio checked 驱动。
- **320px 预算（AC-7）**：tile ≈ (视口 − 弹层留白 − 组内边距 − 列距)/2 ≥ 110px，预览面+名称单行不换行、无横向挤出/堆叠；断点断言锁零溢出。
- **行为（AC-10 不变）**：change 即切皮肤类即时生效（不重载/不重置对局）；持久化 `tetris.dockSkin`（glass|float|fade|pod，默认 fade）与非法回退语义不变；`has-touch=false` 整组不渲染不变。

## 3. 交互与动效

| 场景 | 行为 | 动效 |
|---|---|---|
| 键按压（r16 三态，承继） | 描边转 `--primary`、标签转 `--accent-hi`、辉光 `::before` opacity 0→1、`scale(0.94)` | transform 60ms / border·color 120ms / glow opacity 120ms（r24 定稿值，零改动） |
| 旋转主键 | 常亮环视觉常态呈现；按压仍走上述三态 | 同上 |
| 选择器切换（AC-10 即时生效） | change → 皮肤类替换（r24 既有应用路径），引擎/回放器无感 | 选中描边/勾选显隐 120ms 过渡；**无新动画**（皮肤本身上手即现，不渐变动画——非目标） |
| 键盘操作（AC-9） | radio 组方向键移动、Space/Enter 选中，`:focus-visible` 轮廓清晰（沿用既有 focus token） | 无 |

## 4. 视觉规格

### 4.3 旋转主键主色增强（AC-6）【修订】

对标设计稿（k-hero 视觉）：
- 常亮环：`border:1px solid color-mix(in oklch, var(--primary) 55%, transparent)`（**常态呈现**的紫色描边，替代现偏素灰边）；
- 微底：`background:color-mix(in oklch, var(--primary) 16%, var(--surface-2))`（现深底上过素 → 以常亮环为主导提升突出感，微底维持）；
- 图标 `⟳`：`--primary-hi`；
- 按压态仍走 §3 三态（辉光 `--glow-primary`）。
- 约束：仅 S 竖屏 dock 与手机横屏侧轨作用域；不降低 C 默认态棋盘辨识度（AC-15，QA 截图对拍）。

### 4.4 四皮肤 × 承载（作用域仅 S dock + 手机横屏侧轨）

| 皮肤 | dock（竖屏，承继） | 侧轨（横屏）【修订挂点：`.touchpad::before/::after` → `.rail`】 |
|---|---|---|
| A · 玻璃 dock | `--glass-bg` 玻璃带 + `--line` 上描边 + 上投影 | `.rail--l/.rail--r` 整面板 `--glass-bg` 玻璃 + 上描边（单边描边保留） |
| B · 无底浮键 | 透明，仅键帽浮于背景 | 轨底透明，仅键帽投影 |
| C · 渐隐托盘（默认） | 无描边，底部渐入深玻璃渐变 | 轨内底部渐入渐变（不画整带） |
| D · 双簇座舱 | 十字/主键各一主色光环（静态 gradient，无动画） | 两簇光环对应 `--primary-glow` 系光环托 |

选中开关（选择器）→ 皮肤类挂 `#touch-controls`（r24 机制不变）；横屏皮肤规则改目标 `.rail` 元素，视觉语义与竖屏一致。

### 4.5 作用域约束（AC-12 承继 + AC-3 裁定）

皮肤类、正圆、旋转主色规则**只消费**「S 竖屏 dock + 手机横屏侧轨」两条 media 分支；M/L（≥600px，竖/横）行式底栏恒 `--glass-bg`（不依赖皮肤变量）；桌面视觉零变化。

## 5. 可访问性（AC-9/AC-15）

- **radio 语义**：`input[type=radio]` 真实控件、组内互斥、键盘可达（方向键+Space）、`:focus-visible` 聚焦态沿用既有 focus token（tile 上可见）。
- **选中辨识**：描边+勾选徽标双信号，不依赖颜色单通道。
- **对比度**：C 默认态与四皮肤下棋盘辨识度不降低（微底/常亮环仅触控键区域，不污染棋盘区）。
- **图例**：触屏键位图标+文字双层标签自说明（承继 r16/r24）；非触屏外观组隐藏、键盘图例不变。
- **尺寸**：全部键径 ≥44px 最小点击目标（承继 AC-12 基线）。
