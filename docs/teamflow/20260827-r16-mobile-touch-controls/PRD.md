# PRD — 移动端触屏控制（r16）

## 1. 背景与目标

### 1.1 背景

当前全部游戏操作依赖物理键盘（←/→ 移动、↑/X 旋转、↓ 软降、空格硬降、C/Shift Hold、P/Esc 暂停、R 重开、回车开始、M 静音），手机/平板无物理键盘时完全无法游玩，与「双击 index.html 即玩」的轻量定位相悖。现有 HTML 按钮（开始/暂停/设置/重开/静音等）本身可触，缺口在核心操作区（移动/旋转/下落/Hold）缺少触屏输入通道。

### 1.2 目标

1. **触屏虚拟按键**：左/右/旋转/软降/硬降/Hold 六键，行为与键盘逐键等效（含长按连续输入复用同一速率、每周期 Hold 限 1 次）。
2. **仅触屏渲染**：触摸设备显示触屏控件，纯键鼠设备不显示、布局与体验保持不变。
3. **移动端全流程可玩**：结合现有可触 HTML 按钮（开始/暂停/设置/重开/静音），触屏下从开局到重开无操作死角。
4. **零回归**：引擎规则、7-bag 随机、预览队列、Hold、设置持久化全部不变；键盘游玩路径不受任何影响；七套验证全绿。

### 1.3 成功指标（可量化）

| 指标 | 量化标准 |
|---|---|
| 按键等效性 | 同一固定序列、相同盘面下，触屏输入序列与键盘输入序列产生的棋盘快照 100% 一致（连续比对 ≥ 20 次） |
| 长按连续输入 | 按住移动/软降键 1s 的移动/下落格数 = 键盘按住对应键 1s 的格数，差值 ≤ 1 格（走同一 repeat 时钟） |
| 渲染条件 | 触摸能力检测为真 → 触屏控件可见；为假 → 控件不存在或隐藏，键鼠布局无变化 |
| 防默认行为 | 触摸操作序列后页面滚动位移 = 0px，无缩放/选中/长按菜单触发 |
| 可点击性 | 触屏按钮最小可点击区域 ≥ 44×44 逻辑像素（WCAG 2.5.8 目标尺寸） |
| 回归底线 | 七套验证全绿（97/24/17/2/15/ALL/294）；r15、r14 全部 AC 无回归 |

## 2. 用户故事与验收标准

### US-1：触屏控件随设备显隐

**作为**手机/平板玩家，**我希望**打开页面即出现可用的触屏按键，而键鼠设备上保持原样。

**验收标准**：

- **AC-1（P0）**：触摸能力检测为真的设备渲染并显示触屏控件；纯键鼠设备不显示（或整体隐藏），键鼠布局与现状完全一致；显隐切换不改变游戏状态、不重置对局。
- **AC-2（P1）**：PAUSED / GAME_OVER 状态下点击任意触屏按钮不产生游戏输入、无报错、无副作用，行为与键盘在该状态下的表现一致。

### US-2：核心操作逐键等效

**作为**触屏玩家，**我希望**触屏按键与键盘按键效果完全一致，使操作手感无缝迁移。

**验收标准**：

- **AC-3（P0）**：左/右按钮短按单步移动 1 格（撞墙边界行为一致）；长按连续移动，速率与键盘 ←/→ 一致（按住 1s 格数差值 ≤ 1 格）。
- **AC-4（P0）**：软降按钮短按下落 1 格、长按连续下落，行为与键盘 ↓ 一致（按住 1s 差值 ≤ 1 格）。
- **AC-5（P0）**：硬降按钮点击 = 空格：立即落底锁定，计分/lockFlow/音效事件序列与键盘硬降完全一致（断言 onSfx 事件序列一致）。
- **AC-6（P0）**：旋转按钮点击 = ↑/X 顺时针旋转（含踢墙规则）；固定序列打桩下连续 20 次触屏旋转与键盘旋转盘面 100% 一致。
- **AC-7（P0）**：Hold 按钮点击 = C/Shift：每周期限 1 次、暂存/交换/出生点重置/暂存槽显隐信号均与 r14 规则一致（周期内二次点击无效）。

### US-3：防误触与多触点

**作为**触屏玩家，**我希望**触摸操作只对游戏生效，不会误触浏览器行为，且多指操作互不干扰。

**验收标准**：

- **AC-8（P0）**：触屏控件与游戏区域的触摸事件均 preventDefault（等效 touch-action 约束）：不产生页面滚动、捏合/双击缩放、文本选中、长按菜单；断言滚动位移 = 0px。
- **AC-9（P0）**：多指同时按压不同按钮（如 左+软降、旋转+硬降）各自生效、互不串扰；同一按钮快速连点不产生抖动式重复输入。
- **AC-10（P0）**：触屏输入与物理/蓝牙键盘并存互不干扰，触屏设备上键盘输入仍完整可用（回归护栏）。

### US-4：全流程可达与布局适配

**作为**触屏玩家，**我希望**在手机上能完成从开局、暂停到重开的完整流程，按键不遮挡棋盘。

**验收标准**：

- **AC-11（P0）**：触屏设备上开始/暂停/设置/重开/静音等现有 HTML 按钮全部可点击可用，暂停↔继续循环无死角。
- **AC-12（P1）**：375×667（竖屏）与 812×375（横屏）视口下，触屏控件位于棋盘可视区之外（下方/两侧），不遮挡棋子 ≥ 95% 可视面积，无溢出/塌陷；按钮最小可点击区域 ≥ 44×44 逻辑像素。
- **AC-13（P0）**：触屏设备上键位提示展示触屏说明（或以触屏控件替代键盘图例），不显示误导性键盘文案。

### US-5：零回归

**作为**产品，**我希望**触屏能力是纯增量，桌面键盘与既有功能完全不受影响。

**验收标准**：

- **AC-14（P0）**：六套脚本 + qa-e2e 七套全绿（97/24/17/2/15/ALL/294，新增触屏仿真用例并入 qa-e2e 断言）；r15 多格预览队列（AC-1~12）与 r14 Hold 全部 AC 无回归；桌面键鼠下触屏控件不可见、操作体验不变。

## 3. 范围与非目标

**范围内**：

- 触屏虚拟按键 6 键（左/右/旋转 CW/软降/硬降/Hold）+ 触屏能力检测与显隐。
- 触屏输入通道与键盘共用同一引擎接口与同一 repeat 时钟；触摸事件防默认行为。
- 触屏布局（横竖屏）与可点击性约束；键位提示的触屏适配。
- 触屏控件视觉沿用科技玻璃风格（细节由 DESIGN 阶段细化）。

**非目标**：

- 不做滑动手势（swipe）、拖拽方块、重力感应、长按判定等新交互范式——触屏与键盘规则、随机、计分完全一致，无玩法差异。
- 不新增逆时针旋转按钮（键盘仅顺时针，保持双通道平权；如需 CCW 列为后续需求）。
- 不做外接手柄/蓝牙键位映射。
- 不改变引擎规则、状态机、持久化结构与载荷版本。

## 4. 交互流程摘要

页面加载 → 触摸能力检测（可监听 touchstart / pointer 粗粒度等，实现方式由技术方案定）→ 触屏设备：显示触屏控件；键鼠设备：不显示。触屏按钮按下/抬起 → preventDefault → 映射为与键盘相同的引擎输入调用（左移/右移/软降开始/软降结束/硬降/旋转/Hold），长按连续输入复用键盘既有 repeat 时钟与阈值，触屏路径不另造一套速率。暂停/设置/重开/静音沿用现有 HTML 按钮；横竖屏由 CSS 断点适配。引擎规则与状态机零改动，触屏仅是新增输入通道。

## 5. 优先级

| 优先级 | AC | 说明 |
|---|---|---|
| P0 | AC-1、AC-3~AC-11、AC-13、AC-14 | 触屏可玩性核心：显隐、六键等效、防误触、多触点、全流程可达、图例适配、零回归 |
| P1 | AC-2、AC-12 | 状态鲁棒性与布局/可点击性打磨 |

## 6. 依赖与风险

**依赖**：r15 多格预览队列（基线，预览队列/Hold/持久化通道）、r14 Hold（hold() 接口与 btn-hold 三信号）、r9~r13 既有全部 AC（回归底线）；index.html 现有按钮体系（开始/暂停/设置/重开/静音）直接复用。

**风险与对策**：

| 风险 | 影响 | 对策 |
|---|---|---|
| R1 真机触摸事件与 jsdom 仿真存在差异 | 仿真全绿但真机手感/行为偏差 | jsdom 触屏事件仿真断言 + 真机人工补测清单双轨（沿用 r15 惯例，真机不可得时列明环境限制） |
| R2 iOS Safari 双击缩放/滚动穿透/长按菜单 | 页面抖动、误触发浏览器行为 | preventDefault + touch-action 约束（AC-8），QA 专项验证 |
| R3 触屏按钮遮挡棋盘 | 可玩性受损 | 布局约束 AC-12 + DESIGN 阶段评审控件摆放 |
| R4 长按 repeat 与实体键手感差异 | 操作速率不一致 | 等价性量化指标兜底（AC-3/4，1s 格数差值 ≤ 1） |
| R5 触屏路径另造输入速率常量 | 双通道行为漂移 | 工程约束：复用键盘既有 repeat 机制，禁止另造一套速率数值 |

## 7. 里程碑建议

- **M1 核心可玩（P0）**：触摸检测 + 六键虚拟按键 + 防默认行为 + 键鼠零影响；触屏仿真用例并入 qa-e2e，七套全绿。
- **M2 打磨（P1）**：横竖屏布局、可点击区 ≥ 44×44、键位提示触屏化。
- **M3 发布**：QA 真机补测清单执行（手机/平板设备可得时）+ 产品验收 + 任务夹产物入库。
