## 1. 背景与目标

### 1.1 背景

v2.8 将旋转系统固定为"单点旋转，无踢墙"（AC-18）：旋转碰撞时方块保持原位、返回 `reason: 'wall-kick-denied'`，明确不引入踢墙偏移表。

玩家反馈：踢墙（Wall Kick）是 Tetris Guideline 的通用手感——旋转贴墙/贴块时轻微让位以提高操作流畅度。不同玩家偏好不同（新手希望行为简单可预测、老玩家希望 Guideline 手感），因此应把旋转行为做成**可配置开关**：

1. **当前固定死**：旋转行为无法在两种手感间切换，无法满足两种玩家偏好。
2. **无开关入口**：没有 UI 控件可调整，需改代码才能切换。
3. **踢墙实现缺失**：仅在"无踢墙"一侧可用，需补踢墙偏移表与判定。

### 1.2 目标

1. **新增踢墙开关**：信息面板新增科技玻璃风开关控件（对齐 AC-13 幽灵块开关、AC-15 BGM 开关模式），控制旋转是否踢墙。
2. **默认打开**：新会话默认开启踢墙（符合 Tetris Guideline 主流手感）。
3. **打开=踢墙**：开关开启时，旋转碰撞按标准踢墙偏移表逐格尝试左/右/上偏移，命中则旋转成功（方块 x/y 随偏移更新）。
4. **关闭=无踢墙**：开关关闭时，旋转碰撞保持 v2.8 行为（x/y/rot 不变，返回 `reason: 'wall-kick-denied'`）。
5. **设置持久化**：踢墙开关随 v2.6 持久化通道（localStorage）恢复。
6. **回归稳定**：AC-01 ~ AC-18 全绿，七套验证全绿（默认开启状态下踢墙生效、关闭状态下 AC-18 语义保持）。

### US-19 踢墙旋转开关系统（v2.9 新增）

作为玩家，我希望旋转的踢墙行为可以开关——**默认打开**支持踢墙（符合主流手感），关闭则退回"无踢墙"（保持原位），并能从信息面板随时切换、刷新后记住我的选择。

**验收标准（AC-19）**
1. **开关默认值**：新会话 / 无存档时，踢墙开关**默认打开**——旋转碰撞会尝试踢墙偏移。
2. **打开=踢墙**：开关打开时，旋转碰撞按踢墙偏移表逐格尝试（每方向 1~2 格，含左/右/上/下依标准表次序），命中（偏移后不碰撞且在板内）则旋转成功、方块 x/y 随偏移更新、rot 生效、播放旋转音效。
3. **打开=全部尝试失败则保持原位**：开关打开但所有偏移均失败时，方块维持原位（x/y/rot 均不变）。
4. **关闭=无踢墙（AC-18 语义保持）**：开关关闭时，旋转碰撞保持 v2.8 行为——x/y/rot 均不变、不尝试任何偏移、返回 `{ ok: false, reason: 'wall-kick-denied' }`。
5. **开关实时生效**：游戏中切换踢墙开关后，下一次旋转操作即按新状态执行（≤100ms，无需重开）。
6. **设置持久化**：踢墙开关经 v2.6 localStorage 通道保存，刷新后恢复上次选择；无存档 / 存储不可用时回退默认（开）。
7. **UI 开关控件**：信息面板新增科技玻璃风开关控件（对齐 AC-13/AC-15 模式），含可访问性（Tab 聚焦、`aria-checked`/`aria-pressed`、状态不只靠颜色），开启/关闭状态清晰可视。
8. **零副作用**：不改状态机/消行计分/等级/下落速度/音效引擎/BGM/7-bag/幽灵块开关；**旋转默认行为由"无踢墙"变更为"踢墙开"**（用户可见变更，需显式声明）。
9. **回归底线**：AC-01 ~ AC-18 可自动化项 100% 全绿；七套验证全绿（verify-game / verify-audio / verify-ui / verify-constants / assembly-check / verify-persist / qa-e2e-jsdom）；默认开状态下 AC-18 的旋转保持原位测试改为在"关闭"状态下断言。

> 注：AC-19 是 AC-18 的**演进/可配置化**——AC-18.1 的"旋转碰撞保持原位"在 v2.9 成为"开关关闭时"的行为，不再是无条件的固定规则；AC-02 验证旋转操作可响应，AC-19 验证踢墙开关两种状态的精确旋转行为。需在回归时同步调整 verify-game 中 AC-18 用例前提（默认开需关闭开关或按默认值改写断言）。

## 4. 交互流程概述

```
[待开始 READY] --点击"开始"/回车--> [进行中 PLAYING]
[进行中] --按 P/Esc/失焦--> [暂停 PAUSED]
[暂停] --按 P/Esc/空格--> [进行中]
[进行中] --方块堆顶--> [结束 GAME_OVER] --点击"重新开始"/按 R/空格--> [待开始或直接进行中]
```

- **PLAYING** 旋转行为（v2.9）：
  - 踢墙开关 **开**（默认）：按 ↑/X 旋转 → 计算旋转后形状；若直接合法则原地旋转；若碰撞则按踢墙偏移表逐格尝试（左/右/上依序），命中→按偏移后位置成功旋转，全部失败→保持原位（x/y/rot 不变）。
  - 踢墙开关 **关**：按 ↑/X 旋转 → 若碰撞则保持原位（x/y/rot 不变、无任何偏移），即 v2.8 行为。
- 其余玩法、计分、布局、音效、幽灵块、BGM、7-bag 随机算法与 v2.8 完全一致。

## 5. 游戏规则与数值规格（实现基准）

### 5.1 既有规格（v1.0 ~ v2.7，**v2.9 全部保持，零改动**）

| 项目 | 规格 |
|---|---|
| 游戏板 | 10 列 × 20 行 |
| 方块种类 | 7 种标准 Tetromino（I/O/T/S/Z/J/L），每方块 4 格 |
| 出生位置 | 顶部中间（列 4-5 区域），方块完全可见 |
| 硬降（空格） | PLAYING 态：方块立即落底固定（**不加分**，v2.3 修正）；PAUSED 态：空格 = 继续（v2.1） |
| 计分公式 | 单次消行：1 行=100、2 行=300、3 行=500、4 行=800；乘以当前等级倍率（L 倍率 = L） |
| 升级阈值 | 累计每满 10 行升 1 级 |
| 下落速度 | 等级 L 间隔 = `max(100, 1000 × 0.85^(L-1))` ms（下限 100ms） |
| 游戏结束 | 新方块出生即与已固定方块碰撞 |
| 输入映射 | ←/→ 移动，↑/X 旋转，↓ 软降，空格 硬降（PLAYING）/ 继续（PAUSED），P 暂停/继续，Esc 暂停/继续，R 重新开始 |

### 5.2 踢墙旋转开关规格（v2.9 本次新增）

| 项目 | 规格 |
|---|---|
| 开关键 | 设置键 `tetris.wallKickEnabled`（对齐 v2.6 设置键命名 `tetris.ghostEnabled/bgmEnabled`） |
| 默认值 | **true（开）** |
| 持久化 | 经 v2.6 `persist.js` 通道保存/恢复（刷新恢复上次选择；无存档/存储不可用回退默认开） |
| 旋转方向 | 顺时针 90°（↑/X 键）；逆时针仅用于 API（`rotated(piece, -1)`），UI 无逆时针绑定 |
| 开关=开 | 旋转碰撞 → 按踢墙偏移表逐格尝试（偏移次序固定：右移→左移→上移…，每方向 1~2 格）；命中（`.x+dx,.y+dy` 旋转后 `collides` 为 false 且在板内）→ 按偏移后位置成功（x/y 更新、rot 生效、播放旋转音效）；全部失败 → 保持原位（x/y/rot 均不变） |
| 开关=关 | 旋转碰撞 → **x/y/rot 均不变**、不尝试任何偏移、返回 `{ ok: false, reason: 'wall-kick-denied' }`（v2.8 AC-18 语义） |
| 旋转成功 | `collides(board, next)` 为 false（原地或偏移后）→ `piece.rot = (rot + 1) % 4`，播放旋转音效 |
| 踢墙偏移表 | 仅当开关=开时生效；建议 Guideline 简化单点表（如 `[{-1,0},{+1,0},{0,-1}]` 逐格，具体偏移向量由技术方案定）；表值固定、不可由玩家配置 |
| 确定性 | 相同 board + piece + 开关状态下旋转结果完全确定（偏移尝试次序固定、无随机） |

### 5.3 音效/幽灵块/BGM/持久化/7-bag 规格（v2.0 ~ v2.7，**本次不改**）
