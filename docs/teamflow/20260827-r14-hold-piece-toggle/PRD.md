# PRD — Hold 暂存方块功能（r14）

## 1. 背景与目标

当前版本（r13）的俄罗斯方块缺少 Hold（暂存/交换）机制，玩家无法将当前方块暂存以便后续使用。Hold 是现代 Tetris 的标准功能，可显著提升策略深度。

**目标**：实现 Hold 暂存方块功能，让玩家在游戏过程中将当前方块与暂存槽交换，同时提供设置开关控制该功能的启用/禁用。

## 2. 用户故事与验收标准

### US-1：暂存当前方块

**作为**玩家，**我希望**按下暂存键后，当前方块被存入暂存槽，并立即获得队列中的下一方块继续游戏。

**验收标准**：

- **AC-1**：按下暂存键（C 键或 Shift 键），当前方块被移入暂存槽，下一方块从队列取出成为当前方块，队列补充新方块。
- **AC-2**：暂存槽为空时，按下暂存键，当前方块进入暂存槽，下一方块成为当前方块（等价于 AC-1 的首次使用场景）。
- **AC-3**：暂存槽非空时，按下暂存键，暂存槽中的方块与当前方块交换——暂存槽中的方块成为当前方块，当前方块进入暂存槽。
- **AC-4**：被暂存/交换的方块重置旋转状态为 rot=0，从棋盘顶部中央位置（出生点）开始下落。
- **AC-5**：每个方块下落周期内只能使用一次暂存——当前方块锁定后才能再次使用暂存键（防止连续交换）。
- **AC-6**：暂存操作在 READY/PAUSED/OVER 状态下不响应（仅 RUNNING 状态生效）。

### US-2：暂存槽可视化

**作为**玩家，**我希望**在游戏界面中看到暂存槽中的方块预览，以便了解我暂存了什么。

**验收标准**：

- **AC-7**：暂存槽为空时，暂存预览区域显示为空（或显示占位提示）。
- **AC-8**：暂存槽有方块时，暂存预览区域以与 Next 预览相同的渲染风格（旋转态 rot=0、方块颜色）显示暂存方块。
- **AC-9**：暂存预览区域的位置与 Next 预览区域对称（左侧或上方，与信息面板布局协调）。

### US-3：设置开关控制

**作为**玩家，**我希望**通过设置开关控制 Hold 功能的启用/禁用。

**验收标准**：

- **AC-10**：设置中新增「Hold 暂存」开关，与幽灵块/BGM/踢墙开关交互模式一致（按钮切换、aria-pressed 状态、中文标签）。
- **AC-11**：Hold 开关默认为开启状态。
- **AC-12**：Hold 关闭时，按下暂存键不响应（暂存键被忽略）。
- **AC-13**：Hold 关闭时，暂存预览区域隐藏或显示为不可用状态。
- **AC-14**：Hold 开关状态持久化——刷新页面后保持上次设置（复用 persist.js 现有模式）。
- **AC-15**：Hold 开关切换在 RUNNING 状态下实时生效——关闭时若暂存槽有方块，该方块保留但不再可交换（当前方块锁定后暂存槽清空）。

### US-4：音效反馈

**作为**玩家，**我希望**暂存操作有音效反馈。

**验收标准**：

- **AC-16**：成功暂存/交换时播放 `hold` 音效（新增合成音效）。
- **AC-17**：暂存键被忽略时（Hold 关闭/非 RUNNING 状态/已使用过暂存）不播放音效。

## 3. 范围与非目标

### 范围（In Scope）

- game.js：Hold 核心逻辑（暂存槽状态、交换逻辑、每轮使用限制）
- ui.js：Hold 开关控件 + 暂存预览渲染 + 按键绑定
- persist.js：holdEnabled 设置持久化
- audio.js：hold 合成音效
- index.html：暂存预览区域 DOM 结构 + 设置按钮
- style.css：暂存预览样式
- 测试脚本：verify-game 用例扩展 + verify-ui 暂存契约 + qa-e2e E2E 覆盖

### 非目标（Out of Scope）

- 暂存次数无限制（每个方块下落周期仅限一次，见 AC-5）
- 暂存槽显示多个方块（仅支持一个暂存位）
- 暂存方块的旋转预览（仅显示 rot=0）

## 4. 交互流程摘要

```
玩家按下暂存键（C/Shift）
  ├─ Hold 关闭？ → 忽略（无音效）
  ├─ 非 RUNNING？ → 忽略
  ├─ 本轮已使用过暂存？ → 忽略
  └─ 有效暂存：
       ├─ 暂存槽为空：当前方块 → 暂存槽，next → 当前，队列补充
       └─ 暂存槽非空：当前方块 ↔ 暂存槽交换，next → 当前，队列补充
            └─ 播放 hold 音效
            └─ 重置当前方块 rot=0、出生点位置
            └─ 标记本轮已使用暂存
```

## 5. 数值规格

| 参数 | 值 | 说明 |
|---|---|---|
| holdEnabled 默认值 | `true` | AC-11 |
| hold 键 | `C` / `Shift` | 与主流 Tetris 一致 |
| hold 使用限制 | 每个方块下落周期 1 次 | AC-5 |
| hold 方块出生位置 | 与 spawn 相同（棋盘顶部中央，rot=0） | AC-4 |

## 6. 依赖与风险

### 依赖

- r13 消行动画缓动（lockFlow 子阶段、animMs）—— Hold 的暂存操作不应干扰 clearing 子阶段
- persist.js 现有 settings 模式——holdEnabled 遵循 ghostEnabled/bgmEnabled/wallKickEnabled 模式
- 7-bag 随机队列——Hold 后队列需补充新方块

### 风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| Hold 与 clearing 子阶段交互 | 暂存操作在动画期间触发可能导致状态不一致 | AC-6 限制仅 RUNNING 生效；lockFlow 期间 piece=null，暂存键自然无效 |
| holdEnabled 关闭时暂存槽清空时机 | 暂存槽中方块状态管理 | AC-15 明确：关闭后当前方块锁定时清空暂存槽 |
