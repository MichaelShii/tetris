## 归档规则（TeamFlow 流水线强制）

每轮迭代**更新活文档之前**，产品经理/对应角色先把当前版本文档快照复制到 `docs/history/<版本号>/`：

```
docs/history/v1.0/PRD.md        ← 示例：v1.0 发布时的文档快照
docs/history/v2.0/TECHNICAL.md  ← 示例：v2.0 发布时的文档快照
```

- 快照 = 迭代**开始前**（即上一版本最终态）的文档内容。
- 归档后，活文档即可压缩表述（保留 AC 编号与语义），避免无限膨胀。
- 变更线索以 `AGENTS.md §5 产品记忆`、各文档修订记录、`docs/SUMMARY.md` 为准。
