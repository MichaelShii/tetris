# 俄罗斯方块（Tetris）简化版

自包含静态 Web 小游戏：**双击 `index.html` 即玩**，零构建、零外部依赖、离线可用（`file://` 协议）。
科技玻璃风格（深色背景 + 毛玻璃 + 霓虹光效），覆盖完整的游戏闭环：开始 → 游玩 → 得分 → 难度升级 → 结束 → 重新开始。

## 玩法与规则

1. **目标**：移动并旋转下落的方块，拼满整行使其消除，坚持越久、得分越高。
2. **棋盘**：10 列 × 20 行；7 种标准方块（I / O / T / S / Z / J / L），每次 1 个从顶部居中下落。
3. **计分**（单次消除，× 当前等级）：1 行 = 100、2 行 = 300、3 行 = 500、4 行 = 800；硬降每落 1 格 +1 分。
4. **等级与难度**：累计消除行数每满 10 行升 1 级；下落间隔 = `max(100, 1000 × 0.85^(L−1))` ms（L1≈1000ms，下限 100ms），等级越高下落越快。
5. **游戏结束**：新方块出生即与已固定方块碰撞 → 显示 GAME OVER 与最终分数。
6. **触底缓冲**：方块触底后约 0.5 秒内仍可左右移动/旋转脱离，超时自动固定。
7. **音效（v2.0）**：移动 / 旋转 / 软降 / 硬降 / 消行 / 升级 / 游戏结束七类事件均有 Web Audio API 实时合成音效（零外部音频文件）；信息面板提供音量调节与静音开关（也可按 `M` 键静音）。
8. **暂停/继续快捷键（v2.1）**：`P` 双向切换暂停/继续；`空格` 在暂停态为「继续」快捷键（PLAYING 态仍为硬降）；界面视觉与 v2.0 完全一致。
9. **幽灵块（落点预览，v2.2）**：PLAYING 状态下，当前方块正下方以同色系半透明空心轮廓实时显示其垂直落点投影；不改变任何操作/计分/音效，PAUSED 冻结、READY/GAME_OVER 不显示。

## 操作说明

| 按键 | 动作 |
|---|---|
| `←` / `→` | 左移 / 右移 1 格（按住自动连续移动） |
| `↑` 或 `X` | 顺时针旋转 90°（越界/压块则拒绝） |
| `↓` | 软降 1 格（按住连续软降） |
| `空格` | 硬降：立即落底固定，每格 +1 分；**暂停态按空格 = 继续（v2.1）** |
| `P` 或 `Esc` | 暂停 / 继续（双向切换） |
| `R` | 重新开始（任意状态可用） |
| `回车` / `空格` | READY 态开始游戏；GAME OVER 态重新开始 |
| `M` | 静音 / 取消静音（任意状态可用，v2.0） |

> 页面失焦或切换标签页时**自动暂停**；恢复焦点后需手动按 `P`/`Esc`/`空格` 或点击「继续」恢复。
> 点击控制按钮后焦点自动归还游戏区域，方向键/空格不会误触发按钮（按钮 `mousedown` 已阻止抢焦点）。
> 首次点击/按键后音效即激活（浏览器自动播放策略）；音量与静音设置在同一局会话内保持（刷新页面恢复默认 80%、未静音）。

界面左侧为信息面板：**分数 / 等级 / 消除行数 / 下一个方块预览 / 音量控制**，数值实时刷新并带高亮动效；
页头状态灯显示四态：`READY`（灰）→ `PLAYING`（绿）→ `PAUSED`（金）→ `GAME OVER`（红）。

## 如何运行

- **直接游玩**：双击 `index.html`（或拖入 Chrome / Edge / Firefox 最新版），无需安装任何东西。
- **断网可用**：全部资源为本地文件，DevTools Network 面板请求数 = 0（AC-08）。
- **开发/调试**：直接编辑 `game.js`（核心逻辑）、`audio.js`（音效引擎）、`ui.js`（渲染与 UI）、`style.css`（样式），刷新页面即可，无构建步骤。

## 验收速览

| 验收项 | 覆盖情况 |
|---|---|
| AC-01 开始游戏 | READY 遮罩 + 开始按钮，点击后 300ms 内进入 PLAYING，首块可操作 |
| AC-02 移动/旋转 | ←→ 移动（DAS 170/100ms）、↓ 软降 50ms 重复、↑/X 旋转；碰撞拒绝且原位 |
| AC-03 自动下落与消行 | `performance.now()` 差值计时，间隔与等级表一致；单/多行一次消，触底缓冲 ≤500ms |
| AC-04 暂停/恢复 | P/Esc 切换；失焦自动暂停、恢复不自动继续 |
| AC-05 结束与重开 | 出生碰撞 → GAME OVER + 最终分数；R/按钮重开全量重置，连续多轮无残留 |
| AC-06 计分与升级 | 计分公式与等级阈值由 `game.js` 单测钉死（见 `scripts/verify-game.cjs`）；LEVEL UP toast 800ms |
| AC-07 视觉风格 | 深色底、毛玻璃 `backdrop-filter`、霓虹光效、7 色方块、两分辨率适配 |
| AC-08 自包含与离线 | 仅本地 css/js 引用，无 `http(s)://`，断网可用 |
| AC-09 游戏音效（v2.0） | 7 类事件各自独立合成音效（基频/波形可区分）；仅成功操作触发、消行恰好 1 次；零外部音频文件；自动播放解锁与无声降级；并发上限 4 |
| AC-10 音量与静音（v2.0） | 信息面板音量控件（−/+/静音，复用既有 token）+ `M` 键任意态切换；默认 80%、步进 10%、clamp 0–100%；设置跨重开保持、刷新重置 |
| AC-11 暂停/继续快捷键（v2.1） | `P` 双向切换（既有语义不变）；`空格` 暂停态继续（PLAYING 态仍为硬降）；window 级监听、任意焦点可用；零 UI 视觉改动（截图对比一致） |

**数值自检**：
- `node scripts/verify-game.cjs` — 核心逻辑（Node ≥ 18），覆盖 PRD §5 全部数值公式、方块/旋转/碰撞/消行、状态机迁移矩阵、会话关键路径 + onSfx 事件序列（44 项全绿）。
- `node scripts/verify-audio.cjs` — 音效引擎契约（v2.0）：SFX_DEFS 参数表与 AC-09.1 可区分性、假 AudioContext 下音量/静音/并发/降级/dispose（19 项全绿）。
- `node scripts/verify-ui.cjs` — UI 层契约（导出面 / 常量对齐 / 工厂签名 / 零 DOM 副作用，6 项全绿）。
- `node scripts/assembly-check.cjs` — 装配契约（index.html ↔ audio.js ↔ game.js ↔ ui.js ↔ style.css 的 DOM/API/CSS 钩子交叉核对 + AC-08 自包含审计 + AC-09.5 音频文件审计）。
