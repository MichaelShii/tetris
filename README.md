# 俄罗斯方块（Tetris）简化版

自包含静态 Web 小游戏：**双击 `index.html` 即玩**，零构建、零外部依赖、离线可用（`file://` 协议）。
科技玻璃风格（深色背景 + 毛玻璃 + 霓虹光效），覆盖完整的游戏闭环：开始 → 游玩 → 得分 → 难度升级 → 结束 → 重新开始。

🎮 **[在线试玩](https://michaelshii.github.io/tetris/)**

## 玩法与规则

1. **目标**：移动并旋转下落的方块，拼满整行使其消除，坚持越久、得分越高。
2. **棋盘**：10 列 × 20 行；7 种标准方块（I / O / T / S / Z / J / L），每次 1 个从顶部居中下落。
3. **计分**（仅消行，× 当前等级）：1 行 = 100、2 行 = 300、3 行 = 500、4 行 = 800；硬降/软降/自然落地均不加分。
4. **等级与难度**：累计消除行数每满 10 行升 1 级；下落间隔 = `max(100, 1000 × 0.85^(L−1))` ms（L1≈1000ms，下限 100ms）。
5. **游戏结束**：新方块出生即与已固定方块碰撞 → 显示 GAME OVER 与最终分数。
6. **触底缓冲**：方块触底后约 0.5 秒内仍可左右移动/旋转脱离，超时自动固定。
7. **音效（v2.0）**：移动 / 旋转 / 软降 / 硬降 / 消行 / 升级 / 游戏结束七类事件均有 Web Audio API 实时合成音效（零外部音频文件）；信息面板提供音量调节与静音开关（也可按 `M` 键静音）。
8. **暂停/继续快捷键（v2.1）**：`P` 双向切换暂停/继续；`空格` 在暂停态为「继续」快捷键（PLAYING 态仍为硬降）；界面视觉与 v2.0 完全一致。
9. **幽灵块落点预览（v2.2）**：PLAYING 状态下，当前方块正下方以同色系半透明空心轮廓实时显示其垂直落点投影；PAUSED 冻结、READY/GAME_OVER 不显示。
10. **幽灵块开关（v2.3）**：信息面板提供「幽灵块」开关，可随时开启/关闭落点投影（默认开启；会话内保持，刷新恢复默认）。
11. **背景音乐 BGM（v2.5）**：信息面板提供「BGM」开关（默认关闭），开启后播放 Web Audio 实时合成的循环旋律（零外部音频文件），与既有音量/静音联动（`M` 键/面板静音即时静音 BGM、取消即恢复）；自动播放合规（首次用户交互前不发声）。
12. **持久化（v2.6）**：最高分与四组设置（音量/静音/幽灵块/BGM）通过 localStorage 自动保存，刷新页面恢复上次状态（首次访问使用默认值）。
13. **7-bag 随机（v2.7）**：每 7 块为一轮，将全部 7 种方块洗牌后依次发出，确保每 7 块中每种恰好出现一次，避免连续相同方块。
14. **踢墙旋转开关（v2.9）**：信息面板提供「踢墙」开关（默认开启），开启时旋转碰撞尝试偏移（标准踢墙），关闭时保持原位（`wall-kick-denied`）；开关状态会话内保持、刷新恢复默认。
15. **设置弹层（v3.0）**：点击齿轮图标弹出毛玻璃风格设置弹层，所有设置项（音量/静音/幽灵块/BGM/踢墙）按分组集中管理，弹层打开时游戏自动暂停（v3.0.1）。
16. **消行动画（v3.1）**：消除行时播放 240ms ease-out-quart 亮度脉冲（1→1.25→0，1~4 行同步），动画期间时钟冻结、输入忽略、暂停冻结进度续播；reduced-motion 自动降级为即时消除。

## 操作说明

| 按键 | 动作 |
|---|---|
| `←` / `→` | 左移 / 右移 1 格（按住自动连续移动） |
| `↑` 或 `X` | 顺时针旋转 90°（越界/压块则拒绝；踢墙模式开启时尝试偏移） |
| `↓` | 软降 1 格（按住连续软降） |
| `空格` | 硬降：立即落底固定（**不加分**）；**暂停态按空格 = 继续** |
| `P` 或 `Esc` | 暂停、继续（双向切换） |
| `R` | 重新开始（任意状态可用） |
| `回车` / `空格` | READY 态开始游戏；GAME OVER 态重新开始 |
| `M` | 静音 / 取消静音（任意状态可用） |

> 页面失焦或切换标签页时**自动暂停**；恢复焦点后需手动按 `P`/`Esc`/`空格` 或点击「继续」恢复。
> 首次点击/按键后音效即激活（浏览器自动播放策略）；音量与静音设置在同一局会话内保持（刷新页面恢复默认 80%、未静音）。

界面左侧为信息面板：**分数 / 等级 / 消除行数 / 下一个方块预览 / 音量控制 / 幽灵块开关 / BGM 开关 / 踢墙开关**，齿轮图标打开设置弹层；页头状态灯显示四态：`READY`（灰）→ `PLAYING`（绿）→ `PAUSED`（金）→ `GAME OVER`（红）。

## 如何运行

- **在线游玩**：[点击打开](https://michaelshii.github.io/tetris/)（GitHub Pages 托管）
- **本地运行**：双击 `index.html`（或拖入 Chrome / Edge / Firefox 最新版），无需安装任何东西
- **断网可用**：全部资源为本地文件，DevTools Network 面板请求数 = 0
- **开发/调试**：直接编辑 `game.js` / `audio.js` / `ui.js` / `style.css`，刷新页面即可，无构建步骤

## 项目结构

```
├── index.html         ← 入口（DOM 骨架 + 装配调用 TetrisUI.createUI）
├── style.css          ← 科技玻璃风格全套（tokens / 布局 / 组件 / 降级）
├── game.js            ← 核心引擎（状态机 + 时钟 + 7-bag + 踢墙 + 消行动画 + onSfx 事件）
├── ui.js              ← UI 层（Canvas 渲染 / HUD / 消行脉冲 / 设置弹层 / 装配）
├── audio.js           ← Web Audio 合成音效引擎（7 类音效 + BGM + 音量/静音，零外部文件）
├── persist.js         ← 持久化层（localStorage 读写 + 能力探测降级内存 Map）
├── scripts/
│   ├── verify-game.cjs      ← 核心逻辑自检（74 项，node:test）
│   ├── verify-audio.cjs     ← 音效引擎自检（23 项）
│   ├── verify-ui.cjs        ← UI 层自检（12 项）
│   ├── verify-persist.cjs   ← 持久化自检（11 项）
│   ├── verify-constants.cjs ← 版本一致性自检（2 项）
│   ├── assembly-check.cjs   ← 装配 + 自包含审计
│   └── qa-e2e-jsdom.cjs     ← DOM 级 E2E（248 项）
└── docs/              ← 产品文档（PRD / 设计 / 架构 / 技术方案 / QA 报告）
```
